## Reporting a Vulnerability

We take the security of Custom Store seriously. If you discover a security vulnerability, please follow the guidelines below to report it responsibly.

### How to Submit a Security Report
- **Direct Email**: Please send security vulnerability reports directly to `key76loader@gmail.com`.
- **Public Disclosure**: Please **do not** create public GitHub issues or public discussions for security vulnerabilities.

### Information to Include in Your Report
1. **Description**: Summary of the vulnerability and potential security impact.
2. **Reproduction Steps**: Step-by-step instructions or proof-of-concept (PoC) code to demonstrate the issue.
3. **Affected Components**: Specify whether the issue affects the Frontend (`client`), Backend (`server`), API routes, JWT authentication, or payment integration.
4. **Suggested Mitigation**: Any recommended patches or fixes if available.

### Response & Patch Process
- **Acknowledgement**: We aim to acknowledge receipt of all vulnerability reports within 48 hours.
- **Investigation**: We will investigate and assess the vulnerability severity.
- **Fix & Release**: Security patches will be merged directly into the `main` branch upon verification.
